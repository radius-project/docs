The how-to guides walk you through the tasks involved in setting up and using Radius. They are organized sequentially to follow a typical Radius setup journey:

1. [**Installation**]({{< ref "guides/installation" >}}) – Install Radius on Kubernetes, configure cloud providers, and set up developer workstations
2. [**Resource Types**]({{< ref "guides/resource-types" >}}) – Define and manage the resource abstractions your developers will use
3. [**Recipes**]({{< ref "guides/recipes" >}}) – Implement resource deployments using Terraform or Bicep
4. [**Environments**]({{< ref "guides/environments" >}}) – Configure landing zones for application deployments
5. [**Applications**]({{< ref "guides/applications" >}}) – Define, deploy, update, and troubleshoot applications
